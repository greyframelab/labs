    Odd One Out

    Idea

    What if you could watch sixteen runs of the same roguelike at once? Each run grows from its own seed: the dungeon, the fights, the loot. A scout keeps an eye on all of them and jumps to the one that breaks from the pack, then tells you what makes it strange.

    Controls

    • Auto scout lets the scout pick. It scans a few candidates, locks on and zooms in for a few seconds.
    • Tap or click any run to zoom in yourself. Tap another run to jump to it, or outside to go back.
    • Pin keeps a run in place when you start a new round.
    • Mutate restarts all sixteen as siblings of the run you're looking at: same dungeon, same hero, different luck. Watch them drift apart.
    • New round rolls sixteen fresh seeds. Keyboard: A toggles the scout, N starts a new round, M mutates, P pins, Esc goes back.

    How it works

    Every run is a real simulation: rooms and corridors are generated from the seed, the hero explores with pathfinding, fights what it meets and takes the stairs. The scout compares each run with the median of the round (floor, gold, kills, deaths) and looks for rare floors like vaults, mazes or a boss on floor one. The biggest outlier wins.

    Inspired by

    • A "rule-space explorer" dashboard by @deezzex on X, where an explorer hops across many small simulations to find the one doing something odd.
    • Edward Tufte's small multiples: the same chart repeated so differences jump out.
    • Seeded roguelikes and the communities that share seeds, like daily-seed runs in Spelunky and Slay the Spire.

    For game UI

    Spectator modes, replay browsers, matchmaking monitors and QA tools all have the same problem: too many things happening at once. Show them as small multiples, let the system point at the outlier, and explain why in one plain sentence. Then zoom in and give the evidence.
