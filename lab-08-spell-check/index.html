Spell Check

Idea

What if a spell's incantation was its own source code? The effect on screen is drawn by the formula in the panel, short enough to fit in a 280-character post. Every amber number is a rune: change it and the spell reshapes while you watch the code change.

Controls

  • Drag any amber number in the code left or right to change it. The sliders do the same.
  • Pick a spell (Ward, Vortex, Nova). Its numbers tween in, and so does the shape.
  • Cast (or press Space) charges the spell and releases it.
  • The mana bar is the length of the spell: characters used out of 280.

Inspired by

  • #つぶやきProcessing tweet-sized sketches, such as @yuruyurau's, where the code is posted as part of the piece.
  • Bret Victor's "Inventing on Principle": numbers you scrub in place, with instant feedback.
  • Vogel's sunflower model: points spaced by the golden angle fill a disc evenly.

For game UI

Give VFX a small set of named, tunable parameters and show them right next to the effect. States like charge, cast and cooldown can be the same effect with different numbers, tweened with easing, which keeps them coherent and cheap to iterate.
