Feature Creep

Idea

What if feature creep was an actual creep? A one-page pitch for a small, calm game sits on the desk. A sticky note from the last meeting asks "what if it had multiplayer?", and a centipede made of circuit chips crawls out from under it. Every feature it bites sprouts two more, and each new feature grows it a new segment, so its length is your scope. The list swells, the core features get squeezed, and the ship date slips a few weeks at a time. Cut it and the tail falls off with every feature it added. Peel off the note so no more hatch, catch the head, and the scope locks.

Controls

  • Swipe across the centipede's body to cut it. The tail behind the cut drops, and every feature those segments added falls off the page.
  • Swipe across the head once the body is short to catch it.
  • Drag the sticky note off the page, or press Peel note, so no new centipede hatches.
  • New pitch puts a fresh idea on the page. Restart brings the doc back to its first draft.
  • Keyboard: X cuts the body in half (or catches the head), P peels the note, N new pitch, R restart.

Inspired by

  • "A python is swallowing the Python Wikipedia page" by @explosss1ve, a creature that plays with the page it lives on. The principle taken here: a pun taken literally, as a living thing that changes the content under it.
  • The spider "web crawler" that started this series, crawling over a page of references.
  • Every one-page pitch that came back from a meeting two pages longer.

For game UI

Growth that you can see is growth you can manage. Here the scope has a body: every added feature is one more segment, and its cost (the weeks) sits right next to it in the list. The ship date at the foot of the page keeps the old dates struck through, so the slip reads as a history. The target brackets show what it will bite next, before it happens. The same pattern works for upgrade trees, crafting queues or any budget the player spends: show where each cost came from, and let one gesture undo a whole branch, so the player can see the price of every yes.
